# 📜 Code of Conduct

## Our Commitment

We want Swaadika to be a welcoming and respectful project for everyone.

All contributors are expected to communicate respectfully and contribute in a constructive manner.

## Expected Behavior

- Be respectful and professional.
- Welcome different ideas and perspectives.
- Give constructive feedback.
- Focus on improving the project.
- Help create a friendly environment for contributors.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Offensive or disrespectful comments.
- Trolling or deliberately disruptive behavior.
- Sharing inappropriate content.

## Reporting

If you experience or observe unacceptable behavior, please report it to the project maintainers.

Thank you for helping make Swaadika a welcoming open-source project.
